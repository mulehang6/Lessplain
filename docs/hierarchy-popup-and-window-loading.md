# 层级弹框与工具窗口加载优化

## 已完成

- 层级入口改用原生 JBPopup 列表，沿用现有图表的主题、IDE 界面字体、行间距和图标。
- 层级缩进由行布局表达，当前项单独显示“当前”；长标题提供完整提示，长列表滚动，支持方向键和 Enter。
- 弹框只在打开时创建。关闭、隐藏画布或释放图表时清理弹框与字体监听器。
- 工具窗口的记录、层级、追问画布和根图阅读状态在后台读取。图表页不读取历史列表。
- 节点的待答和已答数量在同一数据库连接中分组读取，避免逐节点开连接、读取完整问题与源码快照。
- 连续刷新合并为最新一次待执行读取；旧结果和已关闭画布的结果不再写回界面。
- 编辑器中的数量与层级刷新同样走后台，保持工具窗口与编辑器的交互一致。

## 卡顿依据与边界

原先窗口组成阶段会同步读取最近记录与完整历史列表、递归追问层级，并逐节点查询注释数量。这些数据库读取在界面线程执行，可能阻塞窗口打开与重绘。ELK 布局原本已经使用独立后台执行器，本次保留其调度方式。

当前没有活动的插件调试会话，因此未取得现场耗时分布。这里记录的是源码确认的阻塞路径及对应修改，不代表已经测得实际启动耗时。画布构造和绘制仍有界面线程开销，若安装后仍明显卡顿，需要再取得运行时证据定位。

## 已验证

- 使用 JDK 21 完成针对性回归与完整 `test`：356 项测试、93 个测试类，零失败。
- 覆盖后台慢读期间 EDT 响应、结果在 EDT 发布、合并刷新、过期结果丢弃、关闭后不回写与失败恢复。
- 覆盖根图和追问归属、普通问题与反馈、失效来源、分组计数、历史与图表页读取范围及阅读状态保留。
- 层级列表完成键盘选择、缩进、当前标记、特殊字符、长标题、滚动范围、字体变化和监听器释放的事件与离屏绘制测试。
- `buildPlugin` 通过；离线 `verifyPlugin` 对 IDEA 2026.1.5 和 2026.2.3 均报告 Compatible。
- API 警告数量保持此前结果：两版分别 4 / 7 个 deprecated 用法，各 8 个 experimental 用法，没有新增警告。
