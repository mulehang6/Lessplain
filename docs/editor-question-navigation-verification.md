# 编辑器提问与节点导航修复

日期：2026-10-19。

## 已实现

- 编辑器选区问题继续保存文件、符号、全文版本、原文和 UTF-16 半开偏移。单独选择 `with` 也有精确位置；Agent 通过问题引用读取来源，不靠当前选中节点猜测。
- 真实源码导航接回同文件分支，复用已打开编辑器并调用 IDEA 原生滚动模型；跨文件继续使用 OpenFileDescriptor。动画遵循 IDEA 设置与平台行为，不增加自有定时器。
- 原生提问框标题提供关闭按钮，外部点击或打开其他窗口不关闭；关闭和 Escape 保留草稿，原有保存和取消行为不变。
- 在源码、教学代码或页面数据编辑器标签内选区提问时不重复创建代码预览。由插件窗口打开问题详情时，继续按冻结来源显示代码预览。
- 节点问题列表和数量标记统一按 viewRef、elementId、nodeId 精确归属，包含该节点的源码选区问题。没有节点身份的问题不猜归属，仍可从全部问题查看。已回答注释与回答页不重复计数。
- 后续实机反馈确认，原生 marker 仍把节点归属限制在高亮片段内。这次移除该包含关系要求：当前已绑定源码编辑器中的非空选区，即使超出片段或位于同文件其他方法，也沿用节点上下文。其他文档编辑器仍隔离，真实选区及后台版本校验不变。
- 注释标记通过元数据更新，不改变布局输入、节点位置或镜头；既有问题及来源无需迁移。
