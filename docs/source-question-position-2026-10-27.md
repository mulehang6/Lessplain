# 源码提问框定位

此前 SourceSelectionQuestionSession 将弹窗锚点固定为编辑区 x=0、当前视口顶部，导致弹窗远离所选代码。

现在在动作触发时取得选区的真实显示坐标，后台冻结来源完成后，将可见部分转换为屏幕坐标。弹窗尺寸计算完成后优先定位在选区下方，保留 8 UI 像素间距；下方放不下则放到上方。靠近屏幕边缘时限制窗口位置，副屏负坐标和任务栏可用区域沿用公共边界处理。

只在首次打开时按选区定位。后续输入扩展和用户拖动继续保留当前窗口位置，不把窗口重新拉回选区。后台完成时编辑器已隐藏或销毁则不弹出；冻结问题、草稿、保存、关闭及输入法行为保持原样。

回归覆盖单行、屏幕底部、右侧边界、多行可见部分、副屏负坐标和超大内容，保留既有弹窗尺寸与原生坐标测试。自动化不启动开发 IDE，实际弹窗距离和主题由用户安装验收。本轮不提交 Git。
