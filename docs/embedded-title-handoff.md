# 画布内嵌标题交接

2026-10-02。用户确认标题固定在视口内，编辑图标 hover 时显示，随标题长度定位；标题与左上工具按钮同一行。

## 实现

- 移除画布外的 BorderLayout 顶栏，画布本身成为完整展示组件。标题只是其中一个透明、紧凑的子组件，不扣除画布高度，不随图平移或缩放。
- 标题放在左上工具按钮右侧，间隔 8 个 UI 逻辑像素。编辑图标为 24 像素目标，紧跟实际显示文字末尾，间隔 8 像素；预留位置，避免 hover 时文字跳动。删除常驻大按钮和标题底板。
- 标题、文字和小铅笔共享 hover 状态，鼠标从文字移到图标时保持可见；键盘聚焦也显示。保留双击、增加 Enter/F2 编辑，并保持从标题切换到铅笔的焦点。
- 窄窗口按可用宽度截短，全文保留在安全 tooltip，避免截断 Unicode 代理对。极窄且容不下图标时保留文字与双击/键盘编辑；容不下省略号时隐藏标题，避免遮挡工具按钮。
- 标题组件仅覆盖自身的紧凑范围，不截获整行事件。编辑弹层跟随标题实际位置；销毁时移除标题监听、键盘动作及编辑回调。
- 本轮不修改协议、记录、节点/边 ID、布局与路由算法，也没有改写已恢复的两张样例。
