## 产品行为

| 行为 | 实现与回归 |
| --- | --- |
| 追问入口看起来像禁用 | 主题强调色问号气泡；笔记使用正常前景色铅笔，禁用状态仍由平台处理。紧凑点击区与数量提示由共用按钮提供。`TutorialPopupInteractionTest`、`NativePopupTest`。 |
| 模拟高亮缺少源码渐变过程 | 源码和模拟共用绘制与 200 毫秒动画；快速切步替换旧进度，重置、资源替换、隐藏、销毁停止计时器，减少动画时直接显示终态。`SourceSweepAnimationTest`、`EditorSourceInsightMarkerTest`、`TutorialResourceLifecycleTest`。 |
| 切到其他编辑器后重复点节点不定位 | 主动点击显式请求定位，普通同步仍去重；固定开关继续生效，当前路线保留。`DiagramSourceActivationTest`、`DiagramEditorNavigationTest`、`DiagramRouteNavigationTest`。 |
| 追问层缺少问题回看 | 层级菜单顶部打开只读分页浮窗；按问题 ID 和冻结上下文读取问题及代码，不从当前文件补造历史。选中回答优先，同层刷新保留当前页，切层跟随只在窗口已打开时发生。`QuestionOriginTest`、`QuestionOriginWindowTest`、`DiagramHierarchyPanelTest`。 |

## 审查发现与修复

| 触发条件／风险 | 修复 | 验证证据 |
| --- | --- | --- |
| 删除理解图后重试图写操作，教程外层缓存可能提前返回已删除结果 | 图创建、修订和图问题答复由 SQLite 事务回执与删除墓碑负责，外层教程缓存不参与 | `GraphMcpLifetimeTest`、`TutorialMcpDurabilityTest` |
| 反馈消费回执嵌套引用已删除记录，重试仍可能读到旧反馈 | 删除时同时检查反馈上下文、消费 ID 与答复 ID，标记相关回执失效 | `RequestLifetimeTest`、`GraphMcpLifetimeTest` |
| A 答案后写入 B，再重试 A，可能让 A 重新成为活动答案 | 答复按规范参数使用事务回执，重试只重放原结果 | `RequestLifetimeTest` |
| 捕获来源、创建问题与删除交错，可能写入失效或错误归属的冻结上下文 | 来源存活、项目归属及问题归属校验与插入放进同一写事务 | `RequestLifetimeTest`、原有来源与删除测试 |
| 并发请求已成功提交，而另一个请求准备阶段失败 | 准备失败后再次查找已提交回执；取消异常继续传播 | `RequestLifetimeTest` |
| 仓库首次初始化失败后，失败 future 阻止重试 | 仅清除仍属于本次加载的失败 future，关闭状态不回退 | `BackgroundResourceTest` |
| 工具读取缓存或初始化时失败，可能逃出结构化错误信封 | 整段回执查询、解析、执行和保存共用错误边界 | `GraphMcpLifetimeTest` 的损坏缓存回归 |
| 已提交结果读取快照失败，入口可能没有登记 | 快照预热失败仍保留待查看结果；项目关闭后不启动提示计时器 | 调用顺序审查、完整回归 |
| 图状态订阅取消后保留空集合；图组件释放后仍注册 tooltip；弹层创建失败泄漏内容组件 | 原子增删订阅并清空空条目；dispose 解除 tooltip 注册；创建失败关闭内容及其订阅 | `GraphViewStateStoreTest`、`QuestionOriginWindowTest`、图与浮窗组件回归 |
| 保存过程中关闭窗口，再打开同一草稿，可能误取消已执行的写入或重复提交 | 草稿共用保存状态；窗口关闭只释放视图；已提交保存仍完成并通知，同一草稿在保存期间不可再次提交 | `CanvasTextEditorTest`；删除旧“关窗即取消保存”断言，保留失败重试覆盖 |
| 键盘聚焦历史行时删除按钮仍隐藏；超过 500 条的旧记录无法进入 | 焦点也显示删除入口；历史查询增加稳定排序与分页 | `UnderstandingPanelDataTest` 的 501 条记录分页回归 |
| 批注计数读取失败引发刷新循环 | 失败只显示可重试图标，不广播服务刷新；成功、关闭时清理重试状态 | 失败回调与监听器顺序审查、完整画布回归 |
| 连线绘制层级与跨线桥优先级不一致；箭头与已有线段互相未检测 | 聚焦、候选、路线共用优先级；箭头和线段双向参与避让 | `DiagramEdgePainterTest`、`ClusterBorderRoutingTest` 及布局回归 |
| 两个 IDE 同时写教程、关闭后继续写、退出时未完成写入与另一个实例竞争 | 文件写入锁；第二实例只读，修改前先校验；最后一个磁盘任务结束才释放锁。只读文档和批注禁改，关闭视图不写阅读状态 | `TutorialStoreLifecycleTest`、教程平台回归 |
| Windows 换行导致表格选区错位；内联或嵌套资源漏渲染、代码字面量误判 | 使用真实源偏移，资源依据 Markdown AST 识别 | `TutorialPreviewModelTest` 的 CRLF、内联、嵌套和代码字面量用例 |
| 同一资源在教程中引用多次，Swing 组件被不同位置争用 | 每个引用位置独立持有组件，资源更新同步刷新所有引用 | `TutorialResourceLifecycleTest` |
| 教程来源路径经符号链接逃出工程 | 对实际文件路径再做工程边界检查 | 路径校验审查与现行精确来源回归 |
| 多文件删除写入中断，遗留答复回执可能复活已删批注 | 加载回执时过滤不存在的批注 | `TutorialStoreLifecycleTest` |
| 已答追问重复提交退回待答；笔记误入提问提交路径 | 提交状态转换与存储同锁；仅问题可提交，非草稿返回已有状态 | `TutorialResourceLifecycleTest` |
| 点击批注里的关联图在 EDT 读数据库；后台回调打开编辑器缺少读域 | 后台读取固定材料，EDT 读域打开；切页、关闭后的旧结果不再打开标签 | `TutorialMaterialNavigationTest`、异步生命周期回归 |
