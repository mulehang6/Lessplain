# 探索路径、分支标记与注释编辑交接

## 本轮范围

探索路径只记录用户实际选择的边。前进一步追加边，后退删除最后一条边；点击路径内节点回到最近一次访问，点击路径外节点从该处开始新路线。恢复状态时校验连续性和终点，不从其他入口重新搜索路线。工具窗口、编辑器和源码提示共用这一规则。

分支标记按 control_flow、call、data_flow 的不同后继节点数大于 1 计算。多入单出不显示标记，同目标平行边只算一个后继，选路仍保留每条边的条件与 ID。删除 decision 字段和专属解析，测量与绘制使用同一判断；历史 JSON 由既有未知字段忽略机制读取，没有增加迁移或旧图特判。协议仍为 3，flowRoles 和 endOutcome 保留。

注释编辑使用原生 Swing 文本组件和公开 JBPopup。固定宽度、默认一行，换行或折行后增高，删除后缩回，最多显示 8 行并受屏幕高度约束。顶部可拖动，内容变化保持移动后的位置；保留中文 IME、UI 字体、Enter 换行和 Ctrl+Enter 保存。标题编辑仍为单行。

非空暂存草稿常驻显示注释气泡。只有草稿时点击恢复编辑，已有注释与草稿共存时提供继续编辑入口。草稿只属于当前画布生命周期，不增加已保存注释数量，也不进入 Agent 待答队列。保存、取消与销毁同步更新入口。

## 回归依据与边界

付费文章图中的两条缺陷注释作为回归依据：从多入口路线经过汇合后回退走错入口，以及另一个入口逐步浏览没有路径流动。测试使用同样的拓扑，不加入 Email 专用逻辑。真实注释及固定上下文保留，没有自动回答、删除或重写。

保留全部既有未提交改动，本轮不提交、不启动 IDE、不操作桌面或截图。实际 IME 输入、拖动弹窗、字体变化和多个画布同步由用户安装新版验收。没有修改布局或路由算法，不重跑性能基准。
