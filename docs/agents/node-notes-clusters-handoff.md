## 本轮实现

有待答注释的节点气泡常驻，无注释节点悬停显示添加入口。悬停预览完整内容，点击固定，逐条选择待答、编辑、删除及添加。删除将待答问题取消，保留来源快照和已回答子图；同一问题的迟到回答被拒绝。

最近菜单、注释和标题编辑使用公开 JBPopup 与 Jewel 主题组件，移除原生窗口标题栏。注释可多行输入，Enter 换行，Ctrl+Enter 保存。外部点击、Esc 或暂时离开画布保留该画布的草稿，取消丢弃，保存清除；回答、删除及销毁清理对应状态、计时器和监听。标题提供悬停、按下、选中反馈，可点击铅笔或双击编辑。

Agent 可按阶段、分支或子流程提交单层分组，不按节点数阈值自动拆分。所有组保持在同一画布，导航聚焦组内目标并保留缩放，显示全图可回到全局。首次分组定位等待异步布局完成。手工分组编辑器和嵌套分组未接入。

`schemaVersion=2` 增加可选 `clusters`，组 ID 唯一、标题和成员非空、节点完整互斥覆盖。新插件继续接受版本 1 无分组请求。修订省略或传 null 保留现有分组，版本 2 的空数组清除；组标题修改使用当前图版本。共享追问画布仅为显示增加组和节点前缀，保留原记录、节点、边与来源身份。

工程内 understanding-frames skill 已校正版本、分组条件、取消语义、固定来源和保存核对；未安装到全局。

## 用户界面验收

安装新 ZIP 后核对明暗主题和缩放下的弹层、键盘焦点及输入，注释从气泡进入预览和点击固定的手感，删除/回答后的入口刷新，以及关闭再打开编辑时的草稿。组标题点击应有反馈，铅笔打开编辑；分组导航应保留缩放与全部组，追问来源跳转准确。
