## 2026-10-01：两阶段多 cluster 布局与通道路由

在同一 Windows 11、28 逻辑处理器环境执行，Gradle 使用 JDK 21，测试进程使用 Java 25.0.4。普通基准仍采用 100 节点预热两次、布局采样三次、1000×700 离屏绘制 30 次；新增真实分组样例每个方向预热一次、采样三次。

命令：`./gradlew.bat test -PgraphBenchmark --tests '*GraphPerformanceBenchmarkTest' --tests '*ClusterLayoutBenchmarkTest' --offline`。两个基准测试均通过；原始报告为 `build/reports/graph-benchmark.txt` 和 `build/reports/cluster-layout-benchmark.txt`。

| 节点 | 边 | 布局中位数 | 绘制 P95 | 已用堆变化 |
| ---: | ---: | ---: | ---: | ---: |
| 100 | 294 | 67.41 ms | 11.94 ms | 4.13 MiB |
| 500 | 1494 | 683.83 ms | 9.45 ms | 18.86 MiB |
| 1000 | 2994 | 1141.88 ms | 3.78 ms | 24.59 MiB |

500 节点布局仍低于 2 秒目标，三个规模的典型视口绘制低于 33 ms。500 节点本次耗时高于上一轮；有限采样、预热和 GC 会影响结果，不能据此断言稳定的性能提升或回退，也不是拖动时帧率。

| 样例 | 节点 / 边 / 组 | 方向 | 布局中位数 | 全图宽 × 高 |

| 文章发布 | 23 / 25 / 5 | 纵向 | 64.35 ms | 2582.5 × 2345.5 |
| 文章发布 | 23 / 25 / 5 | 横向 | 11.53 ms | 4218 × 1263.5 |

| 付费文章 | 41 / 50 / 8 | 横向 | 73.85 ms | 9275.5 × 1265.7 |

文章发布的单节点积分组在两个方向均为 360×192；独立消费者占同一下游层。付费文章有多个依次发生的真实阶段，纵向仍是长图，横向仍是宽图。此轮消除虚构串行依赖和跨组导致的内部空白，并检查线、标签与组内容避让；没有将复杂链路强行压缩到一屏。通道网格仅在带分组障碍且普通候选无解时启用，不用于普通无分组图的每条边。

## 2026-09-29：首轮基准

2026-09-29，在 Windows 11 10.0、28 个逻辑处理器的机器上执行。Gradle 启动与守护进程使用 JDK 21.0.7；IntelliJ 平台测试进程使用 Java 25.0.4。基准源码为 `GraphPerformanceBenchmarkTest`，命令为 `./gradlew.bat test -PgraphBenchmark --tests com.lessplain.diagram.GraphPerformanceBenchmarkTest`。普通 `test` 不执行此基准。下表是在主线平直优先级与层间距调整后重新测得。

每个规模生成一条完整展开的流程，节点分别连接后续 1、2、3 个节点；100 节点预热两次。每个规模测量三次 ELK 纵向布局，取中位数；在 1000×700 的离屏视口绘制 30 次，取 P95。内存变化是在该规模测量前后请求 GC 后的已用堆差值，仅供比较。

| 节点 | 边 | 布局中位数 | 绘制 P95 | 已用堆变化 |
| ---: | ---: | ---: | ---: | ---: |
| 100 | 294 | 45.54 ms | 7.51 ms | 4.30 MB |
| 500 | 1494 | 169.74 ms | 7.54 ms | 17.93 MB |
| 1000 | 2994 | 1068.85 ms | 21.68 ms | 21.46 MB |

500 节点布局与典型视口绘制均低于首轮目标的 2 秒和 33 毫秒。真实 IDE 中的交互体验仍需用户运行后确认。

打包前已有的本地 ZIP 为 14,767,512 字节；加入 ELK 后的 ZIP 为 22,822,332 字节，差值 8,054,820 字节。新引入的 ELK、EMF、Guava 及支持 JAR 在新 ZIP 中的压缩长度合计 8,009,551 字节。前一个 ZIP 来自本地较早构建，故差值还包含少量同期代码与资源变化。依赖声明见 `build.gradle.kts`，许可证说明随插件打包于 `META-INF/third-party-notices.txt`。
