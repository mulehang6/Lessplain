## 已实现

- 历史删除由系统 JOptionPane 改为公开 JBPopup 承载的 Jewel 内容，没有白色系统标题栏。初始焦点在取消，Esc、外部点击和项目销毁均不接受删除；确认对象使用打开时的固定记录 ID。重复确认、切换目标、旧回调与打开失败有独立生命周期处理，删除失败在面板内显示并允许重试。原有记录与追问的级联删除逻辑不变。
- 注释展示使用 Jewel 的默认 UI 文本样式，原生输入框、标题及按钮使用 JBFont。字体来自 IDE 外观设置，与编辑器字体独立；已打开输入面板响应字体和主题变化，销毁后释放监听。保留 Swing 文本输入及 IME 候选保护，不替换成 Compose 输入。
- 一键整理保留画布当前横纵方向和 AUTO/手选偏好，只清除该方向的手动节点位置，另一方向的位置继续保存。异步布局回归等待实际任务结束后核对结果。
- 节点新增可选 `decision=false` 与 `endOutcome=null`，协议仍为 3。结果仅允许 success/failure/null，非空时必须有 end 角色；布尔值及结果类型严格校验。旧记录缺省保持未分类，不自动推断。
- 起点蓝色，成功结束绿色，失败或预期拒绝结束红色，未知或混合结束中性；起止双角色蓝底配结果色边框。决策采用橙色分叉小图标，大小等于节点文字，间距半个字宽，保持矩形节点；文字测量、换行和绘制共用预留宽度，随镜头缩放。
- 上下文新增 `capabilities.nodeSemantics=true`。工程内 understanding-frames 技能已通过 skill-creator 校正，只有能力确认后才发送新字段；角色、决策与结果逐节点按源码判断，不按度数、类别或广播推断。待答问题仍使用固定 token 和 pendingQuestionId，不猜目标。
