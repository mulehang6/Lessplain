# 边说明、编辑器跳转与选区提问

协议仍为 1.4，新增能力 edgeSummaries。GraphEdge.summary 是可选自然语言短句，coverage 是完整源码依据。旧图不需要迁移；没有短句的边以中文关系类型与两端节点作为提示。悬浮正文最多三行，宽度不超过 360 个逻辑像素，不随图缩放改变。右键“查看依据”展开完整说明、条件与关联证据。重叠边不能唯一命中时不打开菜单；右键拖动仍用于平移。

图编辑器使用本地自动跳转状态，初始化为关闭；工具窗口仍使用共享状态。明确点击“在编辑器打开图”时，复用的标签页也关闭跳转。普通标签切换、层级返回不重置。位置、布局和阅读路径继续按图层共享。

“提问”通过公开 Action System 注册到 Floating.CodeToolbar 和 EditorPopupMenu。入口只在具体 Editor 已安装节点源码提示、且存在有效选区时显示。绑定随提示更新和清理，不搜索其他节点。动作事件中的 Editor 提供文档与选区，支持分屏和未保存内容。

点击时固定节点、记录版本、阅读路径与 SourceAnchor。弹层标题使用“提问 · 节点名称”，不再单独显示目标节点行。代码采用 IDEA 公开的只读 EditorFactory 编辑器，带语法高亮、编辑器字体、主题和行号；默认显示前 6 行，长片段在代码块边框内的底部提供居中的展开文字和箭头，展开入口与代码共用圆角边框，展开后最多显示 20 行，超出部分滚动。保留缩进、允许横向滚动，不自动折行。提问输入、错误提示和按钮优先保留屏幕空间。代码以独立文档显示冻结片段，关闭或弹层创建失败时释放编辑器，复用原有文字输入与输入法处理。问题正文不拼接源码，选区通过 context.anchor 进入既有待答批次。草稿和快照一起保留；提交时检查来源版本和节点是否存在，失败保留输入，提示重新选择。成功仍沿用既有待答、回答与删除流程。

节点待答问题列表提供“查看／编辑”，共用上述提问弹层。代码仅从该问题 contextToken 对应的 context.anchor 读取，保存只修改问题正文；切换节点、修改源码或修订图都不会替换既有片段。没有片段的问题仅显示正文，不增加协议字段或数据库迁移。

自动化使用事件、几何、离屏绘制与平台测试，不启动 IDE。实际界面由用户安装构建产物验收。
