# 源码锚点与关系依据

工具参数见 [MCP 协议](../../skills/lessplain/references/protocol.md)，Agent 操作流程见[配套 skill](../../skills/lessplain/SKILL.md)。本页只说明插件的校验与定位约束。

## 提交与保存

Agent 通过 lessplain_context_capture 或 lessplain_source_resolve 取得 sourceId。保存图时按当前 IDE 文档校验，包括未保存编辑；节点、证据及其依赖引用都必须有效，节点也可通过 evidenceIds 定位。

- 文档 SHA-256、精确范围与一基行号由插件解析，Agent 不提交字符偏移或文件哈希。
- 路径及实际文件必须位于工程内，不能通过符号链接越界。片段需唯一、符号需匹配；失败列出引用、路径与原因，不保存半份图或清理待答问题。
- 响应中的 sourceId 可读回来源，lessplain_reveal 返回精确范围。
- 源码读取在 SQLite 写事务外；事务内再次查重，并复核父记录、冻结来源与项目归属。成功重试先重放首次结果，不能恢复已删除记录。

校验只证明引用有效，不证明 Agent 对职责、条件或修改动机的解释正确。

## 回到旧源码位置

旧片段仍存在时按文本与符号定位；只有文本消失才在同文件查找所属函数。唯一函数可回退，多个候选或重载歧义不猜测。

函数回退表示 RELOCATED + CHANGED，提示“仅定位到所属函数，原片段已变化”。不高亮猜测的逻辑块，不显示旧 inline，原证据文本与版本保持不变。当前片段变化时清除旧 inline，图与源码入口仍保留。

定位状态与证据状态分别处理。跨文件移动、依赖实现变化及完整证据 diff 尚不具备完整验证能力，不能把找到同名符号当成语义仍然有效。

## 边说明与推断

边的可选 summary 提供短说明，coverage 保留完整依据；没有短说明时用关系类型和端点提示。悬停显示简短内容，右键“查看依据”展开条件与证据。重叠边无法唯一命中时不猜目标，右键拖动仍用于平移。

推断关系显式设置 inferred=true，并提供非空 coverage。推断边使用轻微虚线，不按 coverage 的措辞自动猜测；已有路径动画和分支选择保持可用。

## 存储边界

理解数据库位于项目的 `.idea/lessplain/understanding.db`，写锁在同目录。第二个 IDE 实例只读；结构迁移前备份，失败保留原库。旧实验目录不自动读取、迁移或删除。
