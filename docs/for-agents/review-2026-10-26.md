本次检查覆盖生产代码、测试、插件注册、MCP、skill、构建及原型。以下保留仍有维护价值的修复依据，后续行为以[主设计](code-understanding-design-v0.5.md)和 [2026-10-28 复审](branch-review-2026-10-28.md)为准。

## 主要修复

| 风险 | 保留的约束 | 回归入口 |
| --- | --- | --- |
| 已删图的写入或反馈消费回执再次重放 | 图操作使用 SQLite 事务回执与删除墓碑；外层教程缓存不能绕过删除 | GraphMcpLifetimeTest、RequestLifetimeTest |
| 重试旧答案覆盖新答案，或捕获来源与删除竞争 | 规范参数去重、来源和问题归属校验放在同一事务，重试只重放原结果 | RequestLifetimeTest |
| 初始化失败无法重试、关闭后仍发布结果 | 仅清除本次失败的加载任务；排队回调检查生命周期，释放订阅与组件 | BackgroundResourceTest、GraphViewStateStoreTest |
| 保存中关窗导致取消提交或重复保存 | 草稿共用保存状态，关闭仅释放视图；成功提交完成后通知，失败可重试 | CanvasTextEditorTest |
| 连线层级与避让规则不一致 | 聚焦、候选和路线共用优先级，箭头与线段双向参与避让 | DiagramEdgePainterTest、ClusterBorderRoutingTest |
| 两个 IDE 写同一教程或退出时过早释放锁 | 第二实例只读，最后一项磁盘任务完成后释放锁 | TutorialStoreLifecycleTest |
| CRLF、重复资源及迟到答复破坏预览或状态 | 保留源偏移，每处引用独立组件；状态转换同锁，失效回执不能恢复删除项 | TutorialPreviewModelTest、TutorialResourceLifecycleTest |
| 批注链接在 EDT 读库，旧回调打开错误材料 | 后台读取固定材料，发布前检查请求及视图状态 | TutorialMaterialNavigationTest |

重复点击节点重新请求源码定位，普通同步继续去重。源码与教学模拟共用 200 毫秒高亮动画，快速切步只保留最新目标。

当时的整层分页回看和切层跟随已被后续单条固定回看替换，现行行为见[导航与删除](navigation-and-deletion-2026-10-27.md)。
