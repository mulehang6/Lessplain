# 图布局性能基准

## 运行与采样

普通 test 默认排除性能基准。使用 JDK 21，在插件目录显式执行：

```powershell
.\gradlew.bat test -PgraphBenchmark --tests 'com.lessplain.diagram.GraphPerformanceBenchmarkTest' --tests 'com.lessplain.diagram.ClusterLayoutBenchmarkTest' --offline
```

原始输出为 `build/reports/graph-benchmark.txt` 和 `build/reports/cluster-layout-benchmark.txt`。基准分别覆盖合成规模图与分组样例，不用于证明源码语义或实际界面体验。

合成图中每个节点连接后续 1、2、3 个节点；先用 100 节点预热两次，每种规模测三次 ELK 纵向布局取中位数，在 1000×700 离屏视口绘制 30 次取 P95。内存为测量前后请求 GC 的已用堆差值。样例图每个方向预热一次、布局采样三次。

## 解释边界

当日 500 节点布局低于 2 秒、典型视口绘制 P95 低于 33 毫秒。样本少，预热、JIT、GC 及运行环境均影响结果，不能据此承诺稳定加速、无回退或实际拖动帧率。

布局与避让的几何检查不等于视觉可读性验收，长图和宽图仍可能难读。比较新旧实现时应保留同一夹具、方向、JVM、预热与采样方法，另行记录真实 IDE 的交互体验。更早的阶段表格与安装包体积可从 Git 历史查阅。
