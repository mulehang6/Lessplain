# 平台线程与生命周期

本页约定后台读取、界面发布和已确认写入的边界。最近验证基线见 [2026-10-28 复审](branch-review-2026-10-28.md)。

## 读取与界面加载

UnderstandingService 使用平台注入的 CoroutineScope 管理后台 IO。UnderstandingStorage 在后台初始化仓库，界面消费记录和浏览状态的内存快照；数据库入口拒绝 EDT 访问，浏览状态按记录合并写入。

工具窗口在后台准备记录、层级、追问画布和阅读状态，图表页不额外读取历史列表。节点待答及已答数量在同一连接中分组读取，避免逐节点打开数据库。连续刷新合并为最新一次请求，旧结果和已关闭画布的结果不能写回。

文件编辑器的同步入口只创建加载外壳，记录与层级在后台准备。层级菜单在打开时创建原生 JBPopup 列表，支持缩进、当前标记、键盘选择、长标题提示与滚动；关闭、隐藏或释放画布时清理弹框及监听器。

历史搜索框、Document 和输入法状态不随后台加载重建，结果只更新列表及分页，见[搜索规则](history-search-2026-10-27.md)。

## 源码与延迟回调

源码选择由 UnderstandingSelection 管理。定位使用平台非阻塞读任务，等待文档提交并绑定项目生命周期；哈希、文本匹配与 PSI 遍历不在界面线程执行。

结果携带文档版本，应用前检查版本、选择、请求代次与项目存活状态。涉及 IDE 模型的延迟操作由 Application.invokeLater 等平台入口调度，不能仅用普通 Swing 回调假定已处于合法读写意图域。平台取消异常继续传播，不转换成普通错误提示。

读取可取消；视图关闭后取消任务并丢弃已排队回调。资源初始化晚于所属对象关闭时，由创建线程释放结果，不能重新打开已关闭仓库。

## 写入与关闭

已确认的持久化操作使用独立串行队列。关闭窗口只释放视图，不取消已经接受的提交；成功后才清除草稿，失败保留可重试内容。项目关闭后排空已接收操作，不再回调界面。

教程队列按文件保留最新失败写入，成功保存其他文件不能掩盖失败。内容、资源、批注及所属回执原子保存；关闭时最后一项磁盘操作完成后才释放写锁，避免第二实例与旧写入竞争。删除的持久化边界见[删除规则](navigation-and-deletion-2026-10-27.md)。

## 验证边界

回归覆盖慢读期间 EDT 响应、刷新合并、过期结果、关闭与初始化竞态、取消传播、写入顺序、故障恢复、图层状态及原生列表事件。具体入口包括 BackgroundResourceTest、ConfirmedWritesTest、PanelRestorePlatformTest、TutorialPersistenceRecoveryTest 和图层加载测试。

ELK 布局由后台执行器完成，画布构造与绘制仍有界面线程开销。源码确认的阻塞路径及测试通过不能代替实际耗时测量；若安装后仍卡顿，需取得运行时证据。真实主题、焦点、菜单和窗口流畅度由用户安装验收。
