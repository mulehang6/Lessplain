# 原生教程实现与验收

本页说明当前教程行为。工具参数见 [MCP 协议](../../skills/lessplain/references/protocol.md)，自动化验证基线见 [2026-10-28 复审](branch-review-2026-10-28.md)。

## 打开、编辑与预览

Understanding 标题栏的书本按钮打开教程目录，可搜索标题与正文。鼠标悬停与键盘选区分别管理，单击或 Enter 打开教程；长标题及路径可查看完整提示，空白区域不命中条目。

教程在独立编辑器标签中打开，默认预览。标签栏右侧使用原版 Markdown 的编辑、分栏、预览图标，通过公开 FileEditor.getTabActions 接入。正文上方不再设置重复按钮条；批注索引与关联源码位于右键菜单。

编辑侧保留同一份原生 IDE Document，自动保存并支持撤销。预览将可见 UTF-16 文字映射到 Markdown 源范围，分栏按源范围双向同步滚动。修改前建立范围标记，连续编辑后仍跟踪原文选区与阅读位置；原文被删除则清空选择。源码链接返回精确范围并完整选中。

## 笔记与追问

一次连续选区对应一条批注。拖选或键盘选区完成后出现追问／笔记入口，与表面所属的原生右键菜单互斥。悬停入口在离开文字与浮条后短暂延迟关闭；主动选区入口保留到取消选区、Esc 或打开批注。

笔记浅黄、追问浅蓝，实际交集浅紫；同类覆盖不叠深。编辑和预览使用相同范围规则。批注窗口可多开、分页、移动和调整尺寸，外部点击不关闭；切回标签后恢复，答复只更新所属窗口，不打断其他输入。

新建空页只存在于当前窗口，不落盘、不高亮、不计数，同组仅保留一个空页。首次非空输入自动保存；清空笔记或未提交问题则移除草稿，窗口保留空页。旧空草稿过滤显示，不批量清理用户数据。

发送图标提交问题并复制载荷，提交后才进入待答队列。已提交或已回答的问题只读；回答可继续选中追问，引用材料提供独立入口。正文删除后的失联批注保留原文快照，可从批注索引找回。

垃圾桶操作需要确认，删除当前笔记或整条问答分支，独立教程和图保留。删除先在后台提交，成功后发布界面变更；失败保留批注并提示重试。引用的图被删除时，只更新链接，不替换窗口内容。

## 图与教学模拟

教程图复用主图画布和手势，圆角边框限定绘制与命中。普通滚轮平移、Shift 滚轮水平平移、Ctrl 滚轮缩放，右键拖动平移，左键拖动节点。左右各留 48 UI 像素供页面滚动，框外正文和留白按页面滚动，正文 Ctrl 滚轮调整字体。标签、人工位置与视角分别保存，一键整理恢复自动布局。

每个资源引用位置独立持有组件，避免同一 Swing 组件被多处争用。正文先引用、资源后保存时更新占位区域；更新保留可复用的模拟组件及播放状态。

模拟使用真实图标工具栏、情境菜单与主题分隔条，可切情境、前后步、重置及横排／上下排列。切换排列保留步骤、输出和分隔比例；输出按步骤前缀恢复，操作只更新相关内容。

步骤高亮沿用源码的 200 毫秒渐变，快速切步只保留最新目标；重置、资源替换、隐藏及销毁停止旧动画。笔迹和高亮按视觉行连续绘制，不被语法颜色切碎。模拟是预设教学内容，不表示真实程序执行。

## 浮窗与输入

目录、最近记录、批注和源码提问共用公开 ComponentPopupBuilder 外壳，使用平台边框、阴影及圆角遮罩。只保留标题栏一个关闭入口，X 有悬停反馈。目录允许外部点击关闭，批注与提问窗口保持打开；X、Esc 和快捷键尊重输入法合成状态。

输入使用 IDE 外观字体，代码预览使用编辑器字体。节点注释每页显示完整文字与冻结代码。源码选区提问只显示输入框，按[选区定位规则](source-question-position-2026-10-27.md)打开，不重复显示已选代码。

## 持久化与删除

教程位于 IDE 持久配置目录的 `lessplain/tutorials/<项目位置哈希>/`。正文、资源、批注、编辑及答复回执合并保存在教程的 `content.json` 原子快照中，阅读状态独立保存；冻结上下文与源码引用由项目级索引管理。第二个 IDE 实例只读，旧实验数据不主动改写或删除。

串行队列按文件保留最新失败写入，其他文件保存成功不清除该失败。flush 重试未完成操作，成功重写清除对应错误；关闭时排空已接收写入，锁在最后一项磁盘任务结束后释放。

教程目录的右键删除需要确认。删除登记先落盘，再清理内容与视图；登记失败可重试，登记成功后的清理失败不会恢复材料，重开项目继续清理。迟到保存、答复及原创建请求不能复活已删教程，详见[删除范围与保护](navigation-and-deletion-2026-10-27.md)。

## 安装验收

自动化采用平台事件、几何和离屏绘制；实际界面仍需安装新版检查：

1. 目录搜索、键盘选择、空白命中和长标题提示，打开教程不挤占工具窗口画布。
2. 编辑、分栏、预览切换，连续编辑与撤销，双向同步滚动，关闭重开恢复模式与位置。
3. 中文、emoji、重复文字及跨段落、代码、表格的选区；真实输入法候选窗与 Esc 行为。
4. 笔记和追问的颜色、多开、分页、空页复用、答复更新、失联批注、删除取消与失败重试。
5. 图框内外滚动边界、主图手势、布局恢复，以及模拟情境、步骤、输出和高亮状态。
6. 深浅主题、字体缩放、窄窗口及浮窗移动和调整尺寸。
