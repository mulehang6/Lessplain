## 源码依据

均通过日常开发 IDEA MCP 阅读，未运行模型或工具来制造执行记录：

- `ChatRunController.sendDraft` 构造请求、收集事件，`cancelActiveRun` 取消运行任务。
- `AgentEventReducer` 把文字片段归入回复，分别处理工具、等待、完成与失败。
- `SendMessageUseCase` 将请求交给 `AgentGateway` 并转发事件。
- `KoogStreamingStrategy` 在模型请求、工具执行、工具结果回传之间连边。
- `KoogAssistantMessageMapper.shouldFinishReactLoop` 要求没有工具调用且存在非空正文。
- `KoogAgentGateway.runWithStopHooks` 在循环结束后检查 Stop Hook，通过后才向外发送完成事件。

模拟文本与输出均是预设教学情境；目录快照与源码点击不表示运行命中。

## 仍需用户体验

先只看第一遍，观察自己能否解释“一句话怎样变成屏幕上的回复”；再决定是否继续第二遍。随后单独在目录页从导出切到状态、再切到 shared，尝试不使用返回按钮找回导出，之后检查返回能否恢复阅读位置。

关注的是是否更容易开始、是否抓住眼前的一段关系、是否知道自己身在何处。测试通过不能证明这些体验成立。页面中的“整段没懂”只展开预写的替代解释，新的 Agent 回答仍使用插件现有交接流程。
