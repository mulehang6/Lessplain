# 源码提问框定位

2026-10-27 修复了弹窗固定在编辑区左上角、远离所选代码的问题。动作触发时取得选区显示坐标，后台冻结来源完成后，将可见部分转换为屏幕坐标。

首次打开优先放在选区下方，留 8 UI 像素间距；下方不足则放上方，位置限制在所在显示器的可用区域内，处理任务栏、副屏负坐标与超大内容。输入扩展和用户拖动后保留当前位置，不重新拉回选区。

后台完成时编辑器已隐藏或销毁则不弹出。窗口只显示问题输入，不重复展示已选源码；提交仍绑定冻结来源，保存失败保留输入。

SourceQuestionPopupPositionTest 及共用弹窗回归覆盖单行、多行可见部分、屏幕底部与右边界、副屏负坐标和超大内容。实际弹窗距离、缩放和主题由用户安装验收，自动化基线见[最近复审](branch-review-2026-10-28.md)。
