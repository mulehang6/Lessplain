# 导航、删除与单条问题回看

本页保留 2026-10-27 调整后的行为约定。完整测试及兼容基线见 [2026-10-28 复审](branch-review-2026-10-28.md)。

## 画布与历史

- 标题栏为教程、历史、在编辑器打开；没有有效画布时显示历史页。
- 工具窗口最后画布按项目保存，包含根图和追问路线，复用已有节点、路径、视角与布局。历史页和编辑器标签活动不覆盖此指针。
- 恢复请求服从用户后续导航；失效时回到历史。自动新结果发布前再次检查活动状态和导航代次，不能抢回已切走的页面。
- 重启后的旧结果保持未读，由用户主动打开。历史列表按所属根记录组织，点击带蓝点条目定位具体回答。菜单及输入规则见[历史搜索](history-search-2026-10-27.md)。

## 问题回看

回答分组标题旁的问号气泡打开该问题及保存时的代码，根图问题位于图标题旁。每次只读一个明确目标，不从当前源码补造历史。

已打开内容固定，切层不会自动换页；显式点击另一个入口才切换，迟到读取不能覆盖新目标。整层回看、首选回答和跟随分页已移除，节点待答注释自身的分页继续保留。

## 删除范围

教程、历史和最近记录共用条目右键“删除”及原生确认框。目标在菜单打开时固定，空白区域无目标，键盘菜单操作选中项，只读实例禁用删除。确认期间保留目录，取消不修改数据。

理解记录按根图整树删除，包括追问与回答。关联编辑器、未读结果及失效画布指针同步清理；删除当前画布后回到历史，删除其他记录保留当前画布及有效返回位置。后台旧列表和旧读取结果不能重新打开已删除记录。

删除教程先阻止新写入，再关闭注册视图、编辑器和批注窗口，清理 Document、虚拟文件与目的地缓存。串行队列先提交 lifetimes.json 删除登记，再清理内容、资源、批注、阅读与布局文件。

登记失败提示重试；登记成功后清理失败返回 CLEANUP_PENDING，材料不再显示，重试或重开继续清理。登记只保留材料、批注、上下文 ID 与创建及请求摘要，不保留正文或答案。

原创建请求即使在正文修改后重试，也识别为原材料；已删除教程的创建、编辑、资源保存及答复返回 DELETED。迟到文档、视角、布局写入和旧回执不能恢复内容。只有用户明确要求重新生成，才捕获新上下文创建新教程。

其他独立图、答案与教程保留，共享源码快照不删除，只回收无引用的教程上下文。其他教程中的引用失效时只更新入口，不重建输入窗口。删除批注分支同样先严格落盘、再发布界面变化，失败保留原内容。

MCP 没有删除工具，普通读取也不执行删除。

## 回归与安装验收

自动化覆盖固定目标、空白命中、键盘菜单、只读与分页；删除登记失败、清理失败、重开清理、旧创建请求和迟到写入；多个打开视图、画布恢复、旧未读及用户导航优先；冻结问题、显式切换与过期结果。

对应入口包括 ListDeletionMenuTest、PanelCanvasSessionTest、PanelRestorePlatformTest、QuestionOriginTest、QuestionOriginWindowTest、TutorialDeletionTest 和 TutorialAtomicStateTest。实际跨重启操作、菜单、标题悬停及浮窗手感仍需用户安装验收。
