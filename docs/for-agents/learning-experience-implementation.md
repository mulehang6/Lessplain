## 产品约定

- 必要节点预先附一份可编辑细讲。必要性按理解门槛判断，不按代码行数。项目对象首次出现时补来源、职责和当前用途，不默认深入被调函数实现。
- 进入细讲后使用整个插件内容区，正文复用教程、插图与模拟。顶部返回主图和切换任意同层主节点；不强迫读完细讲。可将同一内容打开到编辑器 Tab，分别恢复阅读位置。
- 对细讲的补问整合进原文，保存问答历史，不再新增同级解释分支。既有问答和真正的子流程保留。最小范围更新，保护手写正文和笔记，可撤销。
- 教程目录可嵌套、改名、移动和排序，以引用组织同一份材料，避免复制正文。
- 聚焦源码目录跟随当前文件，保留父目录和同级邻居，返回恢复视口，不改原生 Project 树的展开状态。
- 本地保存简短的讲解偏好与已确认背景，不作总水平评分。只在 context_capture/context_read 返回；其他工具不重复。当前明确要求优先，阅读过或提问过不代表已掌握或水平低。

## 实施顺序与验收

1. 精确锚点：保留唯一上下文，内部单独保存 UTF-16 关注范围。图、教程、源码回看与 MCP 读回均保留字段范围；重复词不能误定位，旧锚点仍按整段解释。回归覆盖行内范围、重复上下文、换行规范化和持久化读回。
2. 讲解偏好：用户本地存储与编辑入口；仅上下文工具附带简短当前记录。空记录不阻塞首次阅读，不自动推断或改写个人背景。
3. 教程目录：独立的目录组织数据、嵌套与移动校验，再接原生目录界面。删除目录引用不误删被其他位置引用的材料，既有平面记录继续可见。
4. 节点细讲：节点与唯一教程关联、整区呈现、同层节点切换、原文更新、编辑器同文档与阅读恢复。细讲状态不能篡改主图路径，旧层级不迁移或删除。
5. 聚焦目录：真实项目文件和编辑器选择事件适配；稳定排序、当前分支展开、邻居保留、返回恢复、释放后不再更新。
