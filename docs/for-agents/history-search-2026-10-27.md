# 历史搜索与菜单

2026-10-27 修复了异步加载反复销毁输入框的问题。HistoryPanel 保留同一个搜索框、Document 和输入法状态，后台结果只更新列表及分页；加载、读取失败和成功更新都不能重置文字或光标。

输入停止 180 毫秒后搜索。中文合成尚未确认时暂停查询，确认后提交完整文本，Enter 也可立即查询。连续输入只刷新结果区域。

历史菜单只保留“最近”和“历史”。蓝点表示有未读，不显示数量或独立未读弹窗。未读回答归入所属根记录，打开带点条目定位具体回答并清除对应未读；重启后的旧未读不会自动打开。

历史和最近列表没有额外外框，分页紧凑居中。刷新保留搜索词及合理选区，删除末页最后一项后回退。教程、历史和最近的右键菜单统一显示“删除”，范围见[删除规则](navigation-and-deletion-2026-10-27.md)。

回归覆盖中文合成及后续英文输入、加载和失败时的组件身份、文字与光标保留、蓝点、回答定位、分页及关闭释放，主要入口为 HistoryPanelTest 和 UnderstandingPanelDataTest。真实中文候选窗、主题与键盘操作仍需安装验收；自动化基线见[最近复审](branch-review-2026-10-28.md)。
