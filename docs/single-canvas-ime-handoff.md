## 完成的实现

- 删除公开 `GraphCluster`、`graph.clusters` 解析、语义分组标题写入和默认 root 框。普通记录直接走普通 ELK 布局；共享节点追问仍按一问一组显示，保留内部组导航、标题反馈及真实子记录来源。
- 标题移到画布坐标之外的固定 Swing 栏，长标题截短、完整内容作为安全 tooltip，铅笔和双击继续编辑记录短标题。原问题不变，既有版本校验、历史和标签更新沿用。
- MCP 仅接受 `schemaVersion=3`。节点 `flowRoles` 可为空、start、end 或两者，不使用度数或 `kind` 推断。业务起点蓝色、结束点红色、双角色蓝底红边；悬停及聚焦使用外圈反馈，静态导航语义保持不变。
- 注释和标题编辑改用 JBTextArea/JBTextField 与公开 JBPopup，不使用原生窗口白色标题栏。原生文档和输入法事件保持完整，候选输入中不触发保存/Esc 关闭；按钮保存先结束组合输入，下一次 EDT 事件读取已提交文字，防止重复保存。候选输入期间阻止外部取消，临时输入法窗口激活不关闭编辑器。
- 已有注释仅点击打开，再点同一按钮关闭、点另一节点切换；无注释按钮仍用于添加。删除悬停预览回调、指针状态和开合计时器。弹窗代次避免旧弹窗关闭回调误关新弹窗；画布销毁释放编辑器监听、弹层、草稿和服务订阅。
- 工程内 understanding-frames 技能、README 与主设计同步协议和业务角色。技能仍保留固定来源、pendingQuestionId 映射、当前 revision、完整连续源码及保存返回身份检查。全局技能未修改。
