# 按需教材实验

实验分支为 `experiment/inline-or-generativeui`。原有流程图、分组、源码导航和选区提问继续保留。用户主动选中代码学习时，独立标签页显示教材；源码用准确范围下的细实线提示已有材料，悬停预览后明确打开教材，不占用 gutter。

## 已实现

- 教材支持标题、强调、行内代码、链接、原生代码查看器、表格和复用 ELK 的静态结构图，使用 Swing 与 Java2D，不使用 JCEF。正文跟随 UI 字体，代码跟随编辑器字体；阅读宽度、段间距和换行适应页面。
- 代码查看器关闭灯泡、当前行背景、行号和 gutter，按实际可见行计算高度；长示例仍有“完整示例”入口。普通表格完整展开。
- 来源保存唯一上下文和上下文内的关注范围；教材块可显式关联多个概念。编辑时用 range marker 跟踪，重开时重新验证；失效时隐藏标记并保留材料和笔记。旧教材不制造词级绑定，仍从材料列表进入。
- 相同源码范围合并成一条细线，笔记与追问增强细线；悬停显示类别、数量、相关段落与摘要。重叠范围先显示最具体的关联。普通单击和 IDE 原生导航不改变。
- 学习材料列表跟随按钮，节点菜单跟随鼠标，键盘入口跟随焦点；统一使用 IDE 标准 action popup 的主题选中色。
- 文字与代码选区、表格单元格、图节点都可原位提问或写个人笔记，补充位于目标块下方，可折叠、继续追问。
- 问题冻结课程、块、回答归属、内容哈希和选区；MCP 按 token 回答，不读取当前活动标签页来猜归属。失效目标拒绝追加，保留原问题与笔记。
- 请求幂等、个人笔记独立保存、阅读位置按内容块恢复；图异步布局完成也保留阅读位置。
- 课程、批注、阅读状态和示例存入 IDE 持久配置目录，按项目位置隔离。业务仓库不新增学习源码、模块、测试或排除规则。
- `.main.kts` 示例由实际文件提供内容，用户可打开、修改，使用 IDE Kotlin Script 原生 Run/Debug。插件不自动执行代码。
- 两个既有 MCP 工具通过 `presentation` 扩展教材分支，图协议 1.4 保持兼容。格式见 [教材协议](../skills/lessplain/references/lessons.md)。

## 自动化与实际验收的边界

2026-10-20 自动化结果：完整 `test` 通过，407 项测试、0 失败；`buildPlugin` 成功；`verifyPlugin --offline` 对 IDEA 2026.1.5 和 2026.2.3 均判定 Compatible；`git diff --check` 通过。Verifier 仍报告废弃与实验 API 使用，包括工具窗口接口、编辑器标签标题扩展，以及本轮为显式 UI 读权限使用的 `WriteIntentReadAction`；没有通过反射或降低检查标准隐藏这些提示。

状态与协议测试覆盖冻结目标、并行回答、幂等、失效目标、嵌套追问、个人笔记、表格与图对象、持久化、项目隔离和外置脚本。新增回归覆盖重复同名词、概念分别关联、重叠范围顺序、旧 JSON 与请求指纹兼容、中文和 emoji 的 UTF-16 富文本选区、表格展开和页面宽度。平台组件测试在无窗口的测试平台中创建真实编辑器及教材图，执行笔记保存、刷新、源码跳转、编辑跟踪、关闭重开失效和源码变化后的幂等重试；原生 viewer 还检查阅读装饰关闭、代码块高度增长、长示例高度上限及离屏绘制。

输入框仍持有焦点时，异步回答延迟刷新；离开输入框后更新页面，避免重建正在输入的组件。菜单绘制和弹出位置使用 IDE 标准实现；实际主题悬停、焦点与弹框位置仍需按下列步骤验收。

自动化不启动 IDE。下列行为需要用户安装构建后的 ZIP 验收，不能用单元测试代替：

1. 在 `KoogAgentGateway.run` 选 `Flow<AgentStreamEvent>`，选择“学习选中内容”。把复制内容交给 Agent，检查教材在原标签页更新。
2. 教材先讲 Flow 与 AgentStreamEvent；选择 Flow 的解释追问，再选择回答中的陌生词继续追问。原文、自己的笔记和阅读位置应保留。
3. 依次在表格单元格、图节点和代码选区提问；回答期间切换标签页，结果仍回到原目标。
4. 关闭再打开教材及 IDE，检查折叠状态、个人笔记和阅读位置。确认源码细线悬停预览与 Tools 中的学习材料可重新进入；普通源码点击不打开教材。
5. 打开真实 `.main.kts`，完成 Kotlin 脚本依赖解析、配置 JDK，设置断点后 Debug。修改输出后重新运行，教材与实际文件内容一致。
6. 改动来源或示例后检查失效提示。对照业务仓库 Git 状态，确认没有新增学习文件或构建改动。

## 新 Flow 示例

[flow-native-lesson.json](examples/flow-native-lesson.json) 是独立教材载荷，包含富文本、分别关联到 `Flow` 和 `AgentStreamEvent` 的精确范围、结构图和自包含脚本。自动测试会解析并验证该文件。

加载新版插件后，在目标工程选中 `KoogAgentGateway.run` 的返回类型，使用“学习选中内容”取得新 token，再让 Agent 读取这份 JSON，核实源码后按返回的 `lessonProtocol` 保存。使用新的 `requestId`，不复用旧课程 token。成功返回新的 `lessonId` 后才算安装示例；JSON 文件本身不修改现有课程或笔记。旧运行实例的 `lessonProtocol.version=1` 不支持新关联与富文本，需要先加载新版。

## 当前边界

入口需要真实项目内的选区。重开时源码定位要求上下文唯一，源码搬迁、项目搬迁和 IDE 配置目录变更不会自动迁移。选区以单个正文块、代码块、单元格或图节点为单位，不跨块选择。教材使用固定的教学块集合，不接受浏览器内容或任意组件代码。外部 Agent 交接仍通过复制问题；Kotlin 原生脚本能否运行取决于安装的 Kotlin 插件、JDK 与依赖解析状态。
