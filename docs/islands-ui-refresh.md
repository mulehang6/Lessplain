# Islands UI 改造交接

开发分支：`feat/diagram-jewel-ui`。本轮合并前审查与修复见文末。

## 已完成

插件页面使用 IDE 提供的 Jewel 主题、UI 字体和缩放。范围包括欢迎页、历史与搜索、图表工具窗、独立图编辑器、节点注释及草稿、最近记录弹框、图表设置和删除对话框。源码编辑区保留前后路线按钮，路线选择统一在图表中完成。

图表保留 Swing/Java2D 绘制和 ELK 布局。节点圆角为 8dp，分组圆角为 12dp。

| 节点状态 | 边框 | 底色 |
| --- | --- | --- |
| 起点 | IDE 蓝色，2px 实线 | 蓝色浅底 |
| 结束 | 成功绿、失败红或中性色 | 对应角色浅底 |
| 同时为起点与结束 | 结束结果色 | 蓝色浅底 |
| 当前选中 | 紫色，2px 实线 | 保留角色底色；普通节点用紫色浅底 |
| 临时预览 | 紫色，2px 虚线 | 保留角色底色；普通节点用紫色浅底 |
| 悬停 | 灰色外沿 | 保留角色底色 |

当前选中与预览指向同一节点时，使用实线。候选节点的琥珀色脉动与路径流动沿用原有行为。

紫色使用私有主题键 `MasterUnderstanding.Graph.selection`，浅色回退值为 `#8060DB`，深色为 `#967BEF`。原生列表的蓝色选中行独立保留。

编辑区路线选择弹框已删除，包括列表展示、源码锚定、标题拖动、切标签隐藏和恢复逻辑。源码上／下一步按钮与图表按钮使用同一候选状态：多条路线在图中高亮候选节点，点击节点确认；并行连线按精确 `edgeId` 选择。唯一路线直接前进或后退，无需额外确认。没有显示对应图表时，分叉操作显示 Understanding 工具窗口，切换到对应记录的画布；窗口显示与图表创建完成后执行候选高亮，不自动在编辑区打开图表。

待选期间，图表缩放、平移、显示全图与单击空白保留候选和当前预览。同方向按钮保留现有候选与预览，相反方向切换候选。图中的取消按钮和 Esc 结束选路，取消保留当前视野；点击普通节点取消并跳转。修改相关源码、释放所属编辑器或理解上下文失效时取消。

图表采用统一输入规则，不增加设备模式：普通滚动平移，Shift 修饰的横向滚动水平平移，Ctrl＋滚动围绕光标缩放；支持触摸板连续小数增量。右键按住拖动任意位置平移，右键单击节点在松开时打开菜单；左键仍拖动节点和示例面板，左键拖空白不平移。单指移动指针不改变图表视野。参照 IDEA 2026.1.5 / 2026.2.3 标准图表控制器的 Ctrl＋滚轮缩放规则；Windows 捏合仅在系统或驱动转换成对应缩放事件时响应，未添加原生手势识别或按小数增量猜测设备。

字体变化会重新测量图表、列表和表单。原生窗口边框计入尺寸约束。注释与草稿采用外层 12dp 圆角、16dp 内边距、内层 8dp 圆角和 12dp 分组间距。编辑表单保留输入法合成保护及原有保存、取消操作；关闭时释放字体和输入监听器。

## 2026-10-10 合并前审查与修复

审查覆盖当前工作区的 UI、导航、源码锚点与 schema 修改，确认并修复两处问题：

- 工具窗口尚未完成显示或画布尚未挂载时，连续点击同向源码导航会重复刷新记录并激活窗口。现在相同记录、修订、节点、方向和路线快照复用待完成请求；方向切换、取消和上下文变化使旧请求失效，显示失败后可以重试。
- 原生弹框的位置 API 使用内容原点，尺寸 API 返回外窗大小。现在先扣除边框 inset 取得窗口原点，再约束屏幕边界；设置位置时补回 inset，避免左上边缘越界及反复调整时偏移。

两项问题均先由失败测试复现，再完成修复。新增导航回归覆盖显示完成前后连续点击、后续重新打开、反向切换与失败重试；弹框回归按平台坐标契约覆盖非零边框、负坐标显示器、左上边缘、两种缩放及连续调整。完整测试为 278 项，0 失败、0 错误、0 跳过。实际界面仍需用户安装新版验收。
