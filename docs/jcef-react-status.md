## 已实现

- JCEF、React Flow、elkjs Worker、json-render 保留。三个 MCP 工具仍为 `lessplain_context`、`lessplain_present`、`lessplain_finish_feedback`，创建和更新共用完整页面提交。
- 主页显示历史；历史与编辑器入口保留在 IDEA 原生标题栏。答案画布铺满可用区域，标题放在 Cluster，原问题保存为历史元数据。移除了画布外的重复标题、前言、源码快照与通用输入区。
- 历史右键仅弹“重命名、删除”菜单，支持键盘菜单键、Escape 和外部关闭。重命名单字段编辑，删除单独居中确认全部追问；操作固定目标，不打开综合管理表单或改变归属。
- 旧 Stack/Grid/Card 等容器中的图在展示时投影到统一画布，保留节点、关系、来源及选择路径；不改写持久记录。失配的旧文字组件镜头/位置不用于恢复出的图。图解析失败或未进入画布时明确报错，新提交含图页面强制使用 Board/Cluster/Graph 根。
- 节点只显示最多两行的短 label，左下角仅注释、复制两个图标。注释保留待答列表，下方仅输入框、发送图标和取消；移除节点标题、顶部关闭图标、问题/反馈切换。成功发送清空并关闭，失败留文；取消清空新草稿关闭，Escape/外部关闭保留。新注释统一问题、旧反馈兼容，每条统一显示序号、正文、查看详情和直接删除；编辑与取消编辑移入原生详情，新草稿独立。组件使用相同规则。源码按钮已移除，点击节点是否跳转由开关控制。
- 待答注释硬删除及未提交上下文清理；回答事务保存 answeredNote 版本快照后删除原待答行。原 note: 从回答重建，追问树不丢失。启动时迁移旧 answered/cancelled 行，孤立已答行保留原文恢复 pending；失败、并发和旧引用均受版本校验。
- 恢复左键选中/拖节点、右键拖画布、滚轮纵移、Shift 横移、Ctrl 指针缩放以及键盘导航和单份右键菜单。点击、步骤、组件选择共用 240ms 跟焦，普通单节点保持缩放，可重定向或中断；多分支仅框住并突出候选，橙色候选/紫色预览，原路线恢复普通状态。无左下候选列表，鼠标直接预览确认，方向键循环、Enter确认、Escape退出。
- 起点淡蓝、成功/失败/中性终点恢复不同底色；不同可导航后继显示橙色分支图标。固定控件改为统一细线 SVG、紧凑分组工具条和菜单开关，保持位置；语义色直接读取 IDEA 主题，节点 hover 按钮保持原样。
- 整页只有一个 React Flow 和全局镜头。Cluster 是 ELK compound 父节点，diagram 提供逻辑图，companion 放普通组件或隔离示例；所有内容一起平移与缩放，没有固定卡片内嵌图窗或外层滚动条。分组边界按当前内容重算，不沿用旧大框作为最小尺寸。
- Board.edges 使用 elementId/nodeId 表达真实跨组关系；局部 ID 可重复。组内与跨组 ELK 路径统一转换为全局坐标，步骤在全局拓扑中遍历。一套固定控件操作整张画布；分组导航定位分组，理解层级导航切换独立追问树。按 view 和稳定 host 类型保存镜头与活动分组。
- 图和组件通过独立 JSON Pointer 双向选择，只订阅各图的选择路径；无效及重复组件状态同步不重复跟焦或跳源码。用户再次点击当前节点仍执行 240ms 居中，保持缩放，不重复跳源码或修改路径。
- 图标使用明确 hover、pressed、focus 状态和可见提示；节点、左下按钮栏和扩展连接区保持连续命中，按钮返回节点不隐藏。tooltip 横排，右侧控件优先向左提示；按下按钮、打开弹层及程序聚焦取消提示，主动键盘聚焦仍有提示。语义光标桥接覆盖真实 CEF 内容组件与包装组件，默认浏览器菜单被公开 handler 清除。
