## 删除范围与保护

理解记录沿用根图整树删除。删除当前工具窗口记录会返回历史；删除其他记录保留当前画布和有效返回位置。 删除前取得的列表或后台结果在返回时再次检查快照，不能重新打开已删除的图或覆盖最后画布指针。关联编辑器、未读结果及失效的最后画布指针同步清理。

教程删除先阻止该 ID 新写入，再关闭全部注册视图、编辑器和批注窗口，清理 Document、虚拟文件及目的地缓存。串行写队列先提交 lifetimes.json 删除登记，再删除正文、资源、批注、阅读及布局文件。登记失败保留材料并提示重试；登记成功后文件清理失败会明确提示，重试或重新打开项目继续清理，材料不会重新出现。

删除登记只保留材料 ID、创建和请求摘要、所属批注及上下文 ID，不保留正文和回答。原创建请求即使在正文修改后重试，也识别为原材料。删除后的创建、编辑、资源保存和答复返回 DELETED，迟到文档、视角和布局保存不能恢复文件。清理含正文的旧回执；已有独立图、回答与其他教程继续保留，共享源码快照保留，只回收无引用教程上下文。 已打开的其他教程追问窗口收到引用删除通知时，只更新材料入口，不重建输入区；已无批注引用的所属教程上下文也会在当前删除中回收。

现行 15 个 MCP 工具参数及教程、批注内容模型不变。未新增删除工具，删除由界面明确确认。

## 自动化与安装验收

自动化覆盖右键固定目标、空白命中、键盘菜单、只读菜单和分页几何；教程删除登记失败、文件清理失败、重开清理、正文手改后的创建重试、MCP 迟到调用及多个打开视图；根图和追问恢复、旧未读、用户导航优先、编辑器活动隔离；标题图标几何、单条冻结问题读取、显式切换、删除来源及迟到结果。

最终命令使用 JDK 21：

```powershell
.\gradlew.bat clean test buildPlugin verifyPlugin -Pkotlin.daemon.jvmargs=-Xmx2048m --offline --no-build-cache --rerun-tasks --console=plain
```

自动化不启动开发 IDE。实际主题、标题悬停、右键菜单、窗口关闭与移动手感，以及跨重启操作由用户安装新版后验收。
