# 平台集成的线程与生命周期

本次调整针对数据库阻塞界面、取消异常被当成错误、源码定位在界面线程执行、后台读取缺少生命周期四项问题。

## 已完成

- `UnderstandingService` 接收平台注入的 `CoroutineScope`，项目与插件作用域拥有后台 IO 任务。视图关闭通过返回的取消句柄中断读取，已排队的结果也会检查任务是否仍有效。
- `UnderstandingStorage` 在后台初始化仓库。界面读取记录和浏览状态的内存快照，数据库入口拒绝 EDT 访问；浏览状态按记录合并写入，旧写入不能在新写入之后完成。
- 文件编辑器同步创建只返回加载外壳，后台准备记录、追问画布和层级。注释、历史、标题编辑和节点复制中的数据库操作也移到后台。
- 源码选择由 `UnderstandingSelection` 管理。定位使用 `ReadAction.nonBlocking`、`withDocumentsCommitted` 和 `expireWith`，文档提交、文件哈希、文本匹配和 PSI 遍历不在界面线程执行。
- 定位结果携带文档修改版本，应用前检查版本、选择和任务代次。普通错误才转换为状态提示，平台取消异常继续传播。
- 弹层异步保存成功后才清除草稿并关闭；失败保留输入，关闭弹层取消其保存任务。
- 资源初始化期间关闭项目不会等待磁盘操作。晚到的初始化结果由创建线程释放，取消后的任务不能再次打开已关闭的仓库。

## 验证

针对性回归覆盖后台工作中断、关闭后的排队回调、初始化与释放竞态、合并写入顺序、过期文档、导航路径和异步保存的草稿行为。

已通过完整 test，369 个测试通过，失败、错误和跳过均为 0；buildPlugin 已生成 Lessplain-0.0.1.zip。IDE 对关键服务、选择控制器、存储及编辑器入口的错误级检查均无问题。verifyPlugin --offline 已通过，IDEA 2026.1.5 和 2026.2.3 均为 Compatible，未报告兼容错误或内部 API 使用。报告仍有工具窗口、标签标题和 Compose 嵌入的弃用及实验 API 提示，这些入口的 API 迁移不属于本次四项修复。
