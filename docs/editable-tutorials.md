# 原生教程实施与验收

## 当前行为

Understanding 工具窗口保留图面板。标题栏提供教程书本图标、历史、在编辑器打开，最近记录并入历史菜单。书本按钮弹出标题／正文搜索列表；条目显示标题和关联源码，超宽省略、悬停显示全文。不再提供内置示例按钮。鼠标悬停和键盘选择分别管理，单击或 Enter 打开并关闭目录；提示文字始终来自当前鼠标行，不混用跟随旧选区的扩展行提示。

教程默认预览，通过标签栏右侧的原版 Markdown 图标明确切换编辑、分栏和预览。使用公开 FileEditor.getTabActions，不依赖 Markdown 插件内部实现。正文上方没有额外按钮条，批注索引和关联源码进入右键菜单。编辑侧保留同一份原生 IDE Document，支持自动保存及撤销。预览保留可见 UTF-16 文字与 Markdown 范围的对应。分栏按源范围双向同步滚动。

一次连续选区对应一条批注；完成拖选或键盘选区后出现追问／笔记浮条。右键操作使用表面所属的原生菜单，与入口浮条互斥。笔记与追问保留独立颜色、分页、多开、可移动和调整尺寸的窗口，外部点击不关闭。悬停入口离开文字和浮条后约 200 毫秒关闭；主动选区入口保留到取消选区、Esc 或打开批注。问题提交前是草稿，答复只更新所属窗口。

目录、最近记录、批注和源码提问共用公开 ComponentPopupBuilder 外壳，带标题栏 X、覆盖整窗的圆角 MaskProvider 和平台边框阴影。目录可点击外部关闭；其余窗口保持打开，X 和 Esc 尊重输入法合成状态。内容外边距 12、区块间距 8、图标间距 4、图标点击区域 28，均使用 UI 缩放。批注主题浮窗使用公开 JBPopup，四个图标依次为上一条、下一条、新增和删除，仅保留标题栏一个关闭入口。笔记不构建空回答区；选择回答可继续追问，有引用材料时显示链接。删除前确认，整条追问及其后续问答一并删除，独立材料保留；迟到的保存、答复和回执不会恢复已删除记录。编辑和预览使用相同的范围合并规则：笔记浅黄，追问浅蓝，实际交集浅紫，同类重复覆盖不叠深。

教程图直接复用主图 UnderstandingDiagram 和全部手势：普通滚轮平移、Shift 滚轮水平平移、Ctrl 滚轮缩放、右键拖动平移、左键拖动节点。图默认高 360 UI 像素，圆角边框限定绘制与命中，左右各留 48 UI 像素。框外、正文和留白正常滚动页面，正文的 Ctrl 字体缩放由外层滚动容器处理。标签、位置及视角分别保存；一键整理恢复自动布局。没有宿主处理能力的悬停入口不显示。

教学模拟的按钮、情境菜单和分隔条使用真实组件。操作收进模拟标题旁的原生图标工具栏，情境完整名称和步骤说明显示在状态行。模拟整体、代码区及终端区使用圆角边框；布局图标切换横排／上下排列，切换时保留步骤、输出及横向分隔比例。代码与输出按内容展开，步骤操作更新局部内容；输出按步骤前缀恢复。步骤高亮和批注笔迹按视觉行连续绘制，不受语法颜色切分影响。分栏及模拟使用主题细分隔条。模拟是预设教学内容，不代表真实执行。

新建空页只保存在当前窗口中，不落盘、不高亮、不计数；同组窗口只保留一个空页。首次非空输入自动保存，清空笔记或未提交问题则移除草稿并保留当前编辑状态。历史空草稿只过滤显示，不批量删除。已提交或已回答的问题只读，须用垃圾桶明确删除。追问使用底部右侧发送图标提交并复制问题。

已删除冗余的“学习选中内容”动作、注册及专属交接实现和测试。教程仍由现行 MCP 工具创建。源码选区提问仅显示输入框，按触发时的选区定位，优先紧邻代码下方，空间不足时置于上方并限制到屏幕范围；保留保存／取消和原生默认主按钮；空白草稿关闭即丢弃，冻结上下文保留。节点注释每页直接显示完整文字及冻结代码，使用同一原生弹窗外壳，可移动、缩放；分页、添加、编辑和删除均使用图标。

MCP 仍为 15 个结构化工具，参数见 [协议](../skills/lessplain/references/protocol.md)。正文、资源、批注、阅读状态分开保存在 IDE 配置目录 lessplain/tutorials/<项目位置哈希>。原有用户数据不删除。

教程目录、历史和最近记录的右键菜单统一显示“删除”，确认后才执行。历史菜单仅有“最近”和“历史”，用蓝点表示有未读，不显示数量或单独结果弹窗。历史分页居中显示紧凑图标；列表没有外框。原生搜索框在加载、失败和结果更新期间保持同一实例，中文输入法确认后才搜索，连续输入只更新列表。工具窗口保存最后画布及追问路线，历史页不覆盖此指针；重启不自动打开旧未读结果。回答分组标题旁的问号气泡只回看该回答的问题和冻结代码，切层不更换已打开内容。详细删除保护和本轮验证见 [导航与删除记录](navigation-and-deletion-2026-10-27.md)。

## 安装验收

自动化不启动开发 IDE。安装新版后优先核对：

1. 标题按钮和历史入口能操作可见面板；教程目录不挤占画布，空白区域不命中条目，长标题和路径可通过提示读全。
2. 标签栏右侧编辑、分栏、预览三个图标与原版 Markdown 相同；正文上方没有按钮条。双向滚动对应同一段原文，编辑后撤销，关闭重开恢复模式及位置。
3. 中文、emoji、重复文字及跨段落／代码／表格的连续选区能弹入口，右键菜单不会与入口叠加。
4. 批注主题浮窗没有白色系统标题栏，四个图标和一个关闭入口；笔记没有空回答区或底部无效按钮。多开、分页、关闭、切换标签恢复和收到答复时，不打断输入、不移动正文。删除可取消，确认后清理整条问答分支；混合区域用浅紫色并可分别打开两类批注。
5. 圆角图框边界清楚，内部手势与主图相同，左右留白与框外正文可正常滚动；标签和人工位置保存，整理后恢复布局。
6. 模拟图标工具栏与内容处于同一个圆角区域，情境菜单跟随按钮，横排与上下排列可切换，高亮跨语法颜色连续连接；前后步、重置和资源更新正确恢复输出及高亮，主题细分隔条可拖动且不跳页。
7. 主题、字体缩放、输入法和窄窗口表现。
