# Lessplain

Lessplain 是一个 JetBrains IDE 的插件，用来帮助理解陌生代码及其调用链路。灵感来自 [Understand-Anything](https://github.com/Egonex-AI/Understand-Anything) 和 [Walkthrough](https://github.com/forketyfork/walkthrough-plugin)

以往你向 AI Agent 提问，Agent 读源码后只是输出了一大堆解释文本，而且非常不适合像我一样的初学者，如果你经常使用 GPT 模型进行学习，你就会知道我在说什么，长此以往，阅读障碍都被练出来了。以下是一个**绝望**的例子

```text
我：A 是什么意思？有什么作用
Agent：A 是......。但是在其中混入了你还不知道的 B、C 等概念，因此理所当然地，
你问：那B是什么（因为是输出了一大段，所以你在看到B的时候就已经很疑惑了，根本不会想去看C）

于是，Agent又引出了D，E等概念，此时我就已经迷失了，唯一的选择就是硬着头皮继续看，
但大多数时候我都放弃了
```

而这个插件要做的，就是尽量解决这种痛苦，把答案画成一张图交给插件。图里的每个节点都对应一段真实代码，点一下就能跳过去。看不明白的节点可以直接追问，可以一直嵌套询问，回答会画成新图，挂载到对应的节点下面。

图和源码依据保存在项目本地。主动学习某个概念时，还可以生成独立教材，用文字、代码、表格和静态图逐步说明，并在看不懂的位置追问或记笔记。

## 它能做什么

- **用图回答问题。** 流程、调用、数据来源、条件分支这类问题，Agent 画成节点和连线，而不是几屏文字。
- **点节点跳源码。** 节点锚定到具体代码，点击后打开并定位；切到其他标签后，再点已选节点也会重新定位，固定源码跳转开关仍然有效。当前文件已经打开时平滑滚动过去，源码里也会在对应位置显示一条提示，悬停时高亮关联代码。
- **沿着图读代码。** 点一个节点，插件展开所有能走到它的路径。用“上一步／下一步”顺着连线读，遇到分叉时你自己选走哪条。控制流、调用、数据流、结构、依赖五种关系都能读。
- **在节点上追问。** 需要不停嵌套询问 side question ？在对应节点写下你的疑惑即可。Agent 之后会一次读走所有待答注释，逐条画图回答，回答可引用挂在节点下的理解图或教程，按问题 ID 明确完成。
- **看追问。** 有追问的节点会显示“？”，点它进入这个节点的追问画布。追问可以一层一层往下，窗口里的“返回”和“层级”菜单带你回到任意一层。“层级 → 查看本层提问”可按页回看本层问题和提问时保存的代码；窗口已打开时会跟随切层。
- **看历史。** 欢迎页显示最近记录，历史页可以搜问题和回答。
- **按需学习概念。** 向 Agent 提出想学的问题，由 Agent 生成教程。教程在独立编辑器标签页中打开，先用日常语言说明，遇到不懂的内容可以继续追问。
- **在教材原位追问和记笔记。** 选文字、代码或表格单元格后右键操作，图中可点击节点。笔记和追问在可多开的分页浮窗中显示；回答可继续选中追问，个人笔记独立保存。
- **对比教学情境。** 教程内的只读代码支持预设步骤、代码高亮和模拟终端，明确区分教学模拟与真实执行。

## 需要什么

- JetBrains IDE 2026.1 或更新版本。开发时用 2026.1.5 编译，2026.2.3 实测。
- IDE 自带的 MCP Server 已启用。插件还依赖 IDE 内置的 Compose，不需要 Diagrams。
- 一个能连接 IDE MCP 的 AI Agent。

## 安装

后续个人认为比较成熟后会上传到 JetBrains Marketplace，目前仅限压缩包安装。

1. 拿到安装包 ZIP，没有现成的话参考下面“从源码构建”。
2. 在 IDEA 中打开 Settings → Plugins，点齿轮图标，选 Install Plugin from Disk，选择 ZIP，重启 IDE。
3. 让 Agent 连上 IDE 的 MCP Server。
4. 把仓库里的 `skills/lessplain/`（含 `SKILL.md` 和 `references/`）复制到 Agent 的 skills 目录下的 `lessplain/` 中。这个 skill 告诉 Agent 什么时候该画图、图该怎么画、怎么处理待答注释。

> [!TIP]
> 强烈建议根据个人情况修改一下这个 skill：你是希望尽可能详细地解答（具体到代码逻辑块或者每一行），还是仅链路清晰（一般情况下一个函数就对应一个节点）就够了。
>
> 默认的 skill 只是我个人的偏好，不一定会对你的胃口。

## 怎么用

想在一项开发任务开始前先学习相关代码、审查修改方案，可以试用 [annoy-me](skills/annoy-me/SKILL.md)。它由用户主动开启，在 Agent 中逐轮提问，并用 Lessplain 呈现必要材料。它目前是个人试验，不随插件 ZIP 自动安装；所有 Agent 使用同一份技能目录，安装与调用方式见 [宿主说明](skills/annoy-me/references/agents.md)。

1. 打开 IDE 右侧的 Understanding 工具窗口，保持项目打开，确保 Agent 已连接 IDE MCP。
2. 向 Agent 问一个关于代码的问题，比如“这个请求从进来到写库经过哪些步骤”。最好手动触发一下 skill 。Agent 读源码后把图提交给插件，工具窗口里出现新记录。
3. 点节点读代码。单个值、类型这种一句话能答完的问题，Agent 会直接在对话里回答，不画图。
4. 想深入哪个节点，就给它写一条注释，再让 Agent 回答待答注释。回答出来后，这个节点会出现“？”。

### 图上的操作

| 操作         | 效果                     |
|--------------|--------------------------|
| 滚轮         | 上下平移                 |
| Shift + 滚轮 | 左右平移                 |
| Ctrl + 滚轮  | 以光标为中心缩放         |
| 右键按住拖动 | 在任意位置平移           |
| 右键单击节点 | 打开节点菜单             |
| 左键拖节点   | 手动调整位置，连线跟着走 |

图内还有缩放、全图、一键整理、连线流动、固定源码跳转和自动跟踪节点这几个开关。一键整理只清除当前方向的手动位置。每条历史的根图和每个节点的追问图各自记住这些开关、当前路径、缩放、视口和手动位置。

### 使用教程

1. 向 Agent 说明想学什么，需要时附上源码；Agent 通过 Lessplain 工具保存教程。
2. Understanding 标题栏依次为主页、教程书本图标、历史、在编辑器打开。点击书本搜索标题或正文；单击或 Enter 打开教程。目录可通过右上角 X、Esc 或外部点击关闭。
3. 正文在主编辑区打开，默认预览。标签栏右侧使用 IDEA 原版 Markdown 的编辑、分栏、预览图标；分栏按原文双向联动滚动，自动保存并支持撤销。
4. 选中文字后写笔记或追问。浅黄表示笔记，浅蓝表示追问，同时覆盖的文字使用浅紫；悬停提供强调色问号气泡和正常前景色铅笔图标，已有内容才显示数量。主题浮窗可移动、调整尺寸、多开、分页和关闭，外部点击不关闭，标签切回后恢复。垃圾桶图标在确认后删除当前笔记或整条问答分支；独立教程和图保留。
5. 新建空页不保存、不高亮；首次输入内容后自动保存。清空笔记或未提交追问后移除草稿，窗口继续显示空页。发送图标将问题提交并复制，提交后才进入 Agent 待答队列。答案更新对应浮窗。关闭的批注可从右键菜单“批注索引”找回；正文删除后的失联批注仍保留原文快照。
6. 图可修改节点与连线文字、拖动和恢复布局。教学模拟的操作集中在标题旁的图标工具栏，可切情境、前后步和重置；代码与输出分别放在圆角框内，可横排或上下排列，横排时可拖动分隔条。步骤高亮沿用源码的 200 毫秒渐变铺开，快速切步只保留最新步骤。
7. 教程中的源码链接返回精确范围并完整选中。源码不再安装教材下划线、自动 hover 或 gutter 图标。

正文使用原生 IDE Document，预览使用原生文本流及真实组件。连续选区后自动出现追问／笔记入口。教程图放在带边框的圆角区域中，复用主图画布及手势，左右各留 48 UI 像素供页面滚动；正文普通滚轮滚动文章，Ctrl＋滚轮调整字体。模拟使用原生图标工具栏与主题细分隔条。节点注释每页直接显示全文和保存时的代码，窗口可移动、缩放，分页与编辑、删除使用图标按钮。源码选区提问只显示输入框，不重复显示选中的代码。所有共用浮窗的标题栏 X 都有悬停反馈。实际主题、输入手感和浮窗行为由安装新版后验收，操作清单见 [实验记录](docs/editable-tutorials.md)。
## 数据存在哪

理解图位于项目的 `.idea/lessplain/understanding.db`，是一个 SQLite 文件，包含问题、回答、图的各个版本、源码依据和浏览状态。

- 同一项目在第二个 IDE 实例里打开时，理解数据库和教程存储都只读，避免互相覆盖。
- 数据库结构升级前会先备份，升级失败会回滚。

新教程的正文、资源、批注和阅读位置分别保存在 IDE 持久配置目录 lessplain/tutorials/<项目位置哈希>/。旧实验文件原样保留，不兼容迁移、不主动删除。业务源码与构建配置不受影响。

## 源码定位的限制

定位基于当前编辑器里的内容，包括没保存的修改。节点会记录文件、符号、一段文本和文件哈希。

- 同一段文本出现多次时，插件不会替你猜是哪一处，界面显示定位失败。
- 文件改过但片段仍然唯一、所属符号也对得上时，会重新定位，但不代表原来的解释还成立。
- 源码变化后的证据对比提示还没做完。跨文件移动和依赖语义变化需要更完整的语言适配。

## 目前没有的东西

- 真实运行的 Trace
- 对代码改动的完整 Diff 理解
- 覆盖整个项目的全局图
- 自动把任务交给 Agent。现在只能复制节点来源，再粘贴给 Agent 或 添加注释后主动询问

## 给 Agent 开发者：MCP 工具

插件注册 15 个结构化工具。上下文、查询和定位：context_capture、context_read、materials_list、item_read、source_resolve、reveal；图：graph_create、graph_revise；教程：tutorial_create、tutorial_edit、diagram_save、simulation_save；批注：annotations_list、question_answer、feedback_consume。实际名称均加 lessplain_ 前缀。

对象和数组直接传递。源码引用由插件解析，不需要 Agent 计算偏移、哈希或请求 UUID。正文和资源有各自版本，写入可幂等重试。创建产物与答复已有问题分开，普通读取不消费内容。

完整参数示例见 [协议](skills/lessplain/references/protocol.md)，教学约束见 [配套 skill](skills/lessplain/SKILL.md)。新接口不保留旧工具别名。
## 从源码构建

需要 JDK 21。仓库自带 Gradle Wrapper，在本目录运行：

```powershell
.\gradlew.bat test
.\gradlew.bat buildPlugin
.\gradlew.bat verifyPlugin --offline
```

安装包生成在 `build/distributions/`。`verifyPlugin` 会检查 2026.1.5 和 2026.2.3 两个版本，离线运行需要对应 IDE 已经缓存。

开发时在 IDEA 里打开上一级的 `Agent-dev` 工程，用仓库里的 `Lessplain IDE` 运行配置启动开发实例（2026.2.3）。`runIde` 任务运行 2026.1.5，用来复查最低兼容版本。代码约定、运行配置的细节和 MCP 连接说明见 [AGENTS.md](AGENTS.md)。
