# 可编辑教程工作流

教程使用原生 IDE Document 保存 Markdown，标签栏右侧使用原版 Markdown 的编辑、分栏、预览图标，默认预览。用户连续选区后可直接追问或写笔记。Agent 可以改写正文，版本仅防并发丢写。

## 首次创建

1. lessplain_context_read 或 lessplain_context_capture 获取 contextId 和 sourceId。
2. 读源码，围绕用户当前知识缺口组织文字、代码、表格和必要插图。
3. lessplain_tutorial_create 一次提交 title、markdown、diagrams、simulations。整个提交先校验。
4. 核对返回 ID 和 revision，需要展示时 lessplain_reveal。

Markdown 资源引用：

- 源码：[项目中的返回值](lessplain://source/src_return)
- 插图：![事件传递](lessplain://diagram/delivery)
- 模拟：![情境对比](lessplain://simulation/cold_flow)

diagram/simulation 的 ID 只在所属教程内有效。引用必须有对应资源；source ID 必须由插件解析。

## 分遍阅读与节点细讲

先确定这次要回答的范围，区分完整流程初览、局部节点细讲和既有材料补问，再选图、正文或模拟。面向完整流程时提前备好必要主线，不因拆成几遍而要求用户每读一步就切回 Agent。

- 初览用一个具体输入跟到一个可见结果，只带入走通它需要的概念。开头简短交代还有哪些路径，本遍只展开当前路径。
- 后续各遍在前一遍基础上加入一项有意义的变化，例如一次工具调用，再补循环与结束条件。每遍明确“这次看到哪里就可以停”和仍未覆盖什么；具体例子是理解完整范围的入口，不冒充全貌。
- 必要节点附教程式解释，可内含代码、小图或模拟。先说眼前要解决什么，再解释陌生对象从哪里来、代表什么、为何在此使用。针对有门槛的语法或前提展开，普通条件只简述；一行难懂代码也可以细讲，一串直白赋值无需逐项翻译。
- 正文每段源码引用关注实际解释的词或片段，同时用足够上下文唯一定位；需要对象背景时核实声明与用途，不凭变量名编造职责。函数调用先讲输入、输出和本段用途，内部实现留给真正需要深入的问题。
- 细讲组织在同一份可编辑正文中，不把每个词变成新图节点。主流程、真实子流程和正文内辅助图各有职责；图只在关系表达有助于理解时加入，模拟按需观察且可随时离开。

例如 `val source = window.findConversationOrNull(id) ?: return failure(...)`，先核实并说明 window 所代表的对象及其在当前操作中的职责，接着交代查找目标与找不到时的结果。读者只缺对象背景时，补这段背景即可，无需展开查找函数的完整实现。示例中的具体类型与职责要由项目源码核实，不能照搬到其他工程。

按当前接口保存与组织材料：已有对应教程先更新原文。新讲解用 tutorial_create 创建，返回的教程 ID 放进图节点 tutorialId；同一节点保留一份细讲，避免再创竞争版本。可用 folderPath:["Agent 完整流程","第一遍"] 建议首次目录位置，后续保留用户已整理的目录。读者从节点进入整区细讲，可直接切换同层节点，也可在编辑器中打开同一文档。当前连接的 schema 若缺少这些字段，说明版本限制，不假装已关联；图标签或锚点修订不能冒充完成细讲。

## 持续编辑

读取教程后，lessplain_tutorial_edit 使用 expectedRevision 与 edits:[{find,replace}]。每个 find 必须唯一，顺序作用于上一个替换结果，不做模糊替换。

补问默认改进原细讲：读取待答问题的冻结来源与 materialId，读取对应正文及当前 revision，核实后将新增解释并入相关段落、删除本次造成的重复。用户说“整段没懂”时，留在当前问题里换例子或补必要前提，不要求用户先指出缺少哪个术语。保持已核实内容和用户手写修改，用户笔记不改写；手写内容与修订冲突时只说明冲突局部和建议，不整篇覆盖。只有用户明确要另开主题时才另建独立材料。

正文修订成功后，再用 lessplain_question_answer 完成原 questionId，简述更新了什么并关联同一 materialId。问答历史保留，答案不在正文末尾逐条累加，也不额外生成与原细讲同级的讲解。遇到并发修改重新读取后再整合；正文已删或来源不可核实时说明实际缺口，不重建已删除材料。

图和模拟用专门工具完整更新，资源版本与正文版本独立。图节点的人工位置按 ID 保留。替换模拟后播放回初始状态。正文删掉引用不会自动删除资源或用户批注。

## 教学模拟

每个资源包括 language、只读 code、scenarios。情境包括 id、label、steps。步骤包括从 1 开始的 highlightLines、简短 caption 和可选 stdout。stdout 是本步新增文本；播放界面按步骤前缀重建输出。

模拟没有解释器，不接收任意用户参数。输出来自 Agent 编排，应核对正确性，并与真实观测区分。纯流程演示省略 stdout。需要项目真实行为证据时，使用已有源码或调试器核实，再编写教材。

## 笔记与追问

用户选区由插件冻结为 UTF-16 源范围与原文快照。笔记、问题草稿和答复分别保存。待答问题只在明确提交后出现。question_answer 只更新所属答复，不自动修订正文；对细讲的补问需先完成上面的正文编辑，再提交答复。正文删除后无法定位的批注保留为失联记录，可由索引找回。

笔记浅黄、追问浅蓝，同时覆盖的文字浅紫。浮窗四个图标用于上一条、下一条、新增和删除；窗口右上角关闭只隐藏窗口，批注索引可重新打开。用户确认删除追问时，该条回答和后续追问一并删除，引用的独立材料保留。

Agent 用 lessplain_annotations_list 读取，再 lessplain_question_answer。需要新产物时先创建，再把 materialId 附在答复里。不要用新教程冒充已答复旧问题。
